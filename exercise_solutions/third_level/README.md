# 派生第 3 关

第 8.4.4 节“进一步尝试”的参考解法。以完整配套工程 `color_switch_stages/color_blocks` 为基础，按上一级 README 的顺序建立练习副本。以下文件路径相对于副本根目录：

- `game.gd`
- `levels/level_3.tscn`

首次运行前，按第 7 章的方法把副本的项目名称改为尚未使用的名称，例如 `双色跳台练习8第三关`，让本题使用独立存档。

参考解法为了演示派生和登记的步骤，第 3 关沿用了第 2 关的地形和物体；练习时应在派生场景中自己绘制新的地形。

从主菜单开始，通过第 1 关后选择“下一关”进入第 2 关。第 2 关过关后再次选择“下一关”，确认进入的场景标题为“第 3 关”；第 3 关过关后，结果面板不再显示“下一关”按钮。
