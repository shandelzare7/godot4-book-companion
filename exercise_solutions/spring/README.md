# 弹簧

第 5.5.5 节“进一步尝试”的参考解法。以完整配套工程 `color_switch_stages/player_control` 为基础，按上一级 README 的顺序建立练习副本。以下文件路径相对于副本根目录：

- `objects/spring.gd`
- `objects/spring.tscn`

弹簧的图片可以用 tiles.png 中任意一格；参考解法借用了木板图块。

打开练习副本的 `levels/level_1.tscn`，把 `res://objects/spring.tscn` 实例化到 Objects 下，放在第 28 列高台前的地面上。保存关卡再运行，操控主角走上弹簧，观察弹起的高度。
