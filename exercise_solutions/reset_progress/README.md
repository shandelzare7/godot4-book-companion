# 清除记录

第 7.4.6 节“进一步尝试”的参考解法。以完整配套工程 `color_switch_stages/sound_save` 为基础，按上一级 README 的顺序建立练习副本。以下文件路径相对于副本根目录：

- `game.gd`
- `ui/settings_menu.gd`
- `ui/settings_menu.tscn`

首次运行前，按第 7 章的方法把副本的项目名称改为尚未使用的名称，例如 `双色跳台练习7清除记录`，让本题使用独立存档。

从主菜单打开设置，调节音量后返回，再通过第 1 关生成测试记录。返回主菜单，打开设置并单击“清除记录”。关闭游戏后重新运行副本，确认成绩显示“未完成”，设置中的音量仍是刚才调好的值。
