# 双色跳台

第 4～9 章配套工程（第 9 章完成版）。使用 Godot 4.7.2，Compatibility 渲染器；游戏画面 320×180 像素，窗口 1280×720。

在项目管理器中导入 `project.godot`，项目名称为“双色跳台：完成版”。打开工程后按 F5，从主菜单开始。

## 操作

| 动作 | 按键 |
|---|---|
| 左右移动 | A、D 或方向键 |
| 跳跃 | 空格、W 或上方向键 |
| 切换红蓝 | K 或 J |
| 暂停 | Esc 或 P |

## 玩法

收集金币，避开尖刺和坑，走到关卡尽头的门就过关。关卡里有红、蓝两种砖块：当前颜色的砖块是实心的，另一种颜色变成半透明，可以穿过。站在另一种颜色的砖块里时不能切换，以免卡在砖块中。从上方踩到巡逻敌人可以把它踩扁；切换颜色让敌人脚下的砖块消失，也能让它掉下去。生命有三颗心，用完就失败。过关时记录用时和金币，保存每关最好成绩。

## 文件

| 位置 | 内容 |
|---|---|
| `game.gd` | 全局单例 Game：当前颜色、关卡切换、设置与存档（`user://save.cfg`） |
| `player/` | 玩家场景与脚本 |
| `objects/` | 金币、尖刺、木箱、移动平台、检查点、终点门、巡逻敌人 |
| `levels/` | 第 1 关 `level_1.tscn`；基础关卡 `level_base.tscn` 与继承它的第 2 关 `level_2.tscn` |
| `ui/` | 状态栏、主菜单、设置界面、暂停菜单、结果面板和主题 |
| `assets/` | 图片、音效、背景音乐、中文像素字体与瓦片集，来源见《素材说明》 |

## 碰撞层

| 层 | 名称 | 使用者 |
|---|---|---|
| 1 | world | 地面瓦片、木箱、移动平台 |
| 2 | player | 玩家 |
| 3 | red_blocks | 红砖 |
| 4 | blue_blocks | 蓝砖 |
| 5 | enemies | 巡逻敌人 |

切换颜色时，玩家和敌人的碰撞掩码在第 3、4 层之间换一位。
