## 中文字体

`assets/fonts/fusion-pixel-12px-proportional-zh_hans.ttf` 是 TakWolf 制作的“缝合像素字体”（Fusion Pixel Font）12 像素比例宽度简体中文版，版本 2026.09.25，来自 https://github.com/TakWolf/fusion-pixel-font/releases ，下载文件为 `fusion-pixel-font-12px-proportional-ttf-v2026.09.25.zip`。字体按 SIL Open Font License 1.1 发布，可以随游戏分发；字体文件未修改、未改名。许可原文见 `assets/fonts/OFL.txt`，它所包含的方舟像素字体、俐方体11号、Galmuri 的许可见 `assets/fonts/LICENSES/`。

像素字体要按设计尺寸 12 像素或其整数倍使用，导入设置中关闭了抗锯齿（Antialiasing）、微调（Hinting）和次像素定位（Subpixel Positioning）。

`icon.svg` 是 Godot 新建项目自带的默认图标，许可与署名见前三章工程的《素材说明》。
