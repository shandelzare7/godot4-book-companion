# 小树林

第 2 章配套工程。

使用 Godot 4.7.2，Compatibility 渲染器，窗口为 800×600。

在项目管理器中导入本目录的 `project.godot`。此工程保存第二章完成状态，适合观察、核对和排错；从头跟做时请另建学习项目。

- F5：运行 `forest.tscn`，显示三个 Tree 场景实例。它们的位置不同，共用同一份 `tree.tscn`。
- 打开 `resource_lab.tscn` 后按 F6：左树材质为 Add，右树为独立的 Mix，展示使资源唯一化后的状态。
- 打开 `checkpoints/resource_shared.tscn` 后按 F6：两树共享同一材质。修改其 Blend Mode，可以核对共享实验。
- `tree.tscn` 是可复用部件，根节点及图片节点的局部位置均为零，图片缩放为 3。
- `main.tscn` 保留第一章的关卡草图，打开后按 F6 可回看，也可以用它对照 F5 与 F6 的区别。它由色块和一行标题组成，未挂载脚本。

本章工程没有脚本、按钮连接或分组。第三章不再使用树林，而是新建小机器人舞台，学习脚本、信号与分组。

小树图片为本教材绘制的 64×64 像素素材；保留 SVG 源文件及《素材说明.md》（其中也说明了项目自带的 `icon.svg`），没有复制四本参考书的截图或插图。工程不依赖外部插件。
